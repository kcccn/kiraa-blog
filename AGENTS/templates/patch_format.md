# Agent 输出标准化补丁模板

## 模板结构

以下为 Agent 输出修改建议时必须遵循的格式。每个补丁输出必须包含所有章节，不得省略。

```markdown
## [PATCH] <简短描述>

### 问题/需求概述

<描述当前问题或需求的具体内容。必须包含：>
- 问题现象或需求目标
- 影响的页面类型（首页 / 文章页 / 归档页 / 全局）
- 影响的渲染模式（亮色 / 暗色 / 双端）

### 解决方案详细说明

<描述解决方案的技术路径和实现逻辑。必须包含：>
- 采用的覆盖方式（CSS 变量覆盖 / SCSS 选择器覆盖 / hugo.toml 配置调整 / 模板覆盖）
- 选择该方式的原因
- 实现逻辑说明

### 修改的文件路径列表

| 文件路径 | 操作类型 | 说明 |
|----------|----------|------|
| `<相对路径>` | 新增 / 修改 / 删除 | <变更目的> |

### 代码变更内容

<对每个文件使用 diff 格式标注变更。新增行以 `+` 开头，删除行以 `-` 开头，上下文行以空格开头>

#### `<文件路径>`

```diff
 上下文行（未修改）
- 删除的行
+ 新增的行
  上下文行（未修改）
```

### 清理缓存与测试命令

```bash
# 1. 清理 Hugo 资源缓存
rm -rf resources/_gen/

# 2. 清理构建产物
rm -rf public/

# 3. 启动开发服务器
hugo server --disableFastRender --ignoreCache

# 4. 生产构建验证
hugo --minify
```

### 潜在风险提示

| 风险等级 | 风险描述 | 影响范围 | 缓解措施 |
|----------|----------|----------|----------|
| 高/中/低 | <具体风险> | <受影响的功能或页面> | <预防或应对方法> |
```

## 填写规范

### 问题/需求概述

- **必须**使用客观描述，不得使用模糊词汇
- **必须**明确标注影响范围（页面类型 + 渲染模式）
- 示例：
  - ✅ "文章页暗色模式下，行内代码背景色与正文对比度不足，导致可读性差"
  - ❌ "代码看起来不太对"

### 解决方案详细说明

- **必须**说明覆盖方式和选择原因
- **必须**解释为何不使用其他覆盖方式（如有替代方案）
- 覆盖方式优先级：CSS 变量覆盖 > SCSS 选择器覆盖 > hugo.toml 配置调整 > 模板覆盖

### 修改的文件路径列表

- 使用相对于项目根目录的路径（如 `assets/css/_custom.scss`，而非 `d:\kiraa-blog\assets\css\_custom.scss`）
- 操作类型必须为"新增"、"修改"、"删除"三者之一
- **不得**出现 `themes/FixIt/` 下的任何文件路径

### 代码变更内容

- 使用标准 unified diff 格式
- 每个修改的文件单独一个 diff 代码块
- 上下文行数量：前后各保留 2-3 行，确保变更位置可唯一定位
- `+` 和 `-` 后面必须紧跟一个空格
- 对于 `hugo.toml` 的修改，使用 TOML 语法高亮

### 清理缓存与测试命令

- **必须**包含缓存清理命令
- **必须**包含开发服务器启动命令
- **必须**包含生产构建验证命令
- 命令必须可直接在终端中执行，无需额外修改

### 潜在风险提示

- 风险等级定义：
  - **高**：可能导致页面不可用或内容丢失
  - **中**：可能导致部分功能异常或样式错乱
  - **低**：仅影响边缘场景，不影响核心功能
- 每个风险必须包含缓解措施
- 如无风险，填写"无已知风险"

## 示例

```markdown
## [PATCH] 修复暗色模式下行内代码背景色对比度不足

### 问题/需求概述

文章页暗色模式下，行内代码背景色 `rgba(233, 105, 0, 0.15)` 与正文背景色 `#292a2e` 对比度不足，导致行内代码在暗色模式下难以辨识。影响页面类型：文章页。影响渲染模式：暗色模式。

### 解决方案详细说明

采用 SCSS 选择器覆盖方式，调整暗色模式下行内代码的背景色透明度。选择该方式的原因：行内代码样式已通过 `!important` 在 `_custom.scss` 中覆盖，CSS 变量无法覆盖 `!important` 声明，因此需直接修改选择器中的颜色值。

### 修改的文件路径列表

| 文件路径 | 操作类型 | 说明 |
|----------|----------|------|
| `assets/css/_custom.scss` | 修改 | 调整暗色模式行内代码背景色 |

### 代码变更内容

#### `assets/css/_custom.scss`

```diff
     :not(pre) > code {
         color: #e96900 !important;
         background-color: #f8f8f8 !important;
         
         [data-theme='dark'] & {
-            background-color: rgba(233, 105, 0, 0.15) !important;
+            background-color: rgba(233, 105, 0, 0.25) !important;
         }
 
         font-family: "JetBrains Mono", Consolas, monospace;
```

# 1. 清理 Hugo 资源缓存
rm -rf resources/_gen/

# 2. 清理构建产物
rm -rf public/

# 3. 启动开发服务器

# 4. 生产构建验证

```

### 潜在风险提示

| 风险等级 | 风险描述 | 影响范围 | 缓解措施 |
|----------|----------|----------|----------|
| 低 | 透明度增加可能导致部分暗色背景下行内代码过于突出 | 文章页暗色模式 | 验证时检查多种暗色背景下的视觉效果 |
