# Agent 输出标准化补丁模板

## 模板结构

Agent 提供修改建议时，必须按以下格式输出。所有章节必须完整，不得省略。

```markdown
## [PATCH] <简短描述>

### 方案概述

<描述问题/需求及解决方案。必须包含：>
- 问题现象或需求目标
- 采用的覆盖方式（CSS 变量覆盖 / SCSS 选择器覆盖 / hugo.toml 配置调整 / 模板覆盖）
- 选择该方式的原因

### 修改的文件路径

| 文件路径 | 操作类型 | 说明 |
|----------|----------|------|
| `<相对路径>` | 新增 / 修改 / 删除 | <变更目的> |

**约束**：路径不得包含 `themes/FixIt/` 下的任何文件。

### 代码变更

<使用 diff 格式。新增行以 `+` 开头，删除行以 `-` 开头，上下文行以空格开头>

#### `<文件路径>`

```diff
  上下文行
- 删除的行
+ 新增的行
  上下文行
```

### 清理缓存与测试

```bash
# 清理 Hugo 资源缓存与构建产物
rm -rf resources/_gen/ public/

# 启动开发服务器（禁用缓存）
hugo server --disableFastRender --ignoreCache

# 生产构建验证
hugo --minify
```

**注意事项**：
- 修改 SCSS 后必须清理 `resources/_gen/`，否则浏览器可能加载旧样式
- 验证时必须切换亮色/暗色模式确认双端兼容
- 浏览器硬刷新：`Ctrl + Shift + R`
```

---

## 填写规范

| 章节 | 要求 |
|------|------|
| 方案概述 | 必须说明覆盖方式和选择原因，不得使用模糊描述 |
| 修改的文件路径 | 使用项目根目录相对路径，操作类型限"新增/修改/删除" |
| 代码变更 | 标准 unified diff 格式，每个文件单独一个代码块 |
| 清理缓存与测试 | 必须包含缓存清理、开发服务器启动、生产构建三条命令 |
